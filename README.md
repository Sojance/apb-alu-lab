Что делает

APB slave (ведомое устройство шины APB), которое умеет выполнять над двумя 32-битными числами три операции:

- Инверсия — побитовое НЕ от первого операнда (`~A`)
- XOR — сложение по модулю 2 (`A ^ B`)
- Сравнение — проверка на равенство (`A == B`), плюс бонусом проверка `A > B`

Регистры (младшие 4 бита адреса)

- `0x0` — **OPERAND1**, чтение/запись — первый операнд
- `0x4` — **OPERAND2**, чтение/запись — второй операнд
- `0x8` — **CONTROL**, чтение/запись — управление:
  - биты `[1:0]` — код операции
  - бит `[2]` — старт (после выполнения сбрасывается автоматически)
- `0xC` — **RESULT**, только чтение — результат последней операции

Коды операций (поле `CONTROL[1:0]`)

- `00` — инверсия: `RESULT = ~OPERAND1`
- `01` — XOR: `RESULT = OPERAND1 ^ OPERAND2`
- `10` — сравнение на равенство: `1`, если равны, иначе `0`
- `11` — сравнение «больше»: `1`, если `A > B`, иначе `0`
